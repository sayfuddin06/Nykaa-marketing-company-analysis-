# Nykaa Marketing Performance Dashboard

## Executive Summary

This project presents a professional **Marketing Performance Analytics Dashboard** developed in **Power BI** using a simulated Nykaa marketing dataset.

The dashboard delivers comprehensive insights into:

* Campaign performance
* Marketing ROI
* Audience segmentation
* Revenue generation
* Channel effectiveness
* Campaign loss analysis

The solution was designed to replicate a real-world business intelligence reporting environment used by modern e-commerce and digital marketing teams.

# Business Problem

Marketing teams run thousands of campaigns across multiple digital channels, but measuring:

* ROI performance
* Audience profitability
* Channel efficiency
* Campaign losses
* Revenue contribution

can become difficult without centralized analytics.

This dashboard solves that problem by transforming raw campaign data into actionable business insights.

# Dataset Information

The dataset contains marketing campaign information including:

| Column            | Description                     |
| ----------------- | ------------------------------- |
| Campaign_ID       | Unique campaign identifier      |
| Channel_Used      | Marketing channels used         |
| ROI               | Return on investment            |
| Revenue           | Campaign revenue                |
| Spend             | Campaign spending               |
| Audience          | Target customer segment         |
| Campaign_Duration | Campaign duration category      |
| Conversion_Rate   | Customer conversion performance |
| Loss_Label        | Campaign loss indicator         |

---

# Key Insights

Some important insights generated from the dashboard include:

* Social media and SEO campaigns achieved the highest ROI.
* Premium shoppers generated the largest revenue contribution.
* Long-duration campaigns slightly outperformed short campaigns.
* High acquisition costs significantly impacted campaign losses.
* Multi-channel campaigns produced stronger marketing performance.
